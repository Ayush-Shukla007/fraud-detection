# Data Directory

## Credit Card Fraud Detection Dataset

This directory holds the training dataset. The application supports the **Kaggle Credit Card Fraud Detection** dataset format.

---

## Recommended Dataset

**Dataset:** [Credit Card Fraud Detection — Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

**File:** `creditcard.csv`

**Size:** ~144 MB

---

## Dataset Format

The dataset must be a CSV file with the following columns:

| Column | Type | Description |
|--------|------|-------------|
| `Time` | float | Seconds elapsed since first transaction |
| `V1` - `V28` | float | PCA-transformed features (anonymized) |
| `Amount` | float | Transaction amount |
| `Class` | int | Target: 0 = Legitimate, 1 = Fraud |

---

## Download Instructions

### Option 1: Kaggle CLI
```bash
pip install kaggle
kaggle datasets download -d mlg-ulb/creditcardfraud
unzip creditcardfraud.zip -d ./data/
```

### Option 2: Manual Download
1. Go to https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
2. Sign in to Kaggle
3. Download `creditcard.csv`
4. Place it in this `data/` directory

---

## Demo Mode

If no dataset is provided, the application runs in **DEMO MODE** using a synthetic dataset generated by `ml/demo_data_generator.py`.

To generate demo data:
```bash
cd ml
python demo_data_generator.py
```

This creates `data/demo_transactions.csv` for batch detection testing.

## Dataset Statistics (Kaggle dataset)

- Total transactions: 284,807
- Fraud transactions: 492 (0.172%)
- Legitimate transactions: 284,315 (99.828%)
- Features: 30 (Time, V1-V28, Amount)
- Target: Class (0/1)

> ⚠️ The dataset is highly imbalanced. The training pipeline handles this automatically using class weights and/or SMOTE.
